# Summit Robotics brand assets

Regenerate everything with `npm run brand` (source: `generate.mjs`).
All text is outlined, so no fonts are needed to use the files.

**Colors:** orange `#e85d04` · dark `#0a0a10` · white `#ffffff`  
**Typeface:** Space Grotesk (Medium for SUMMIT, Bold for ROBOTICS and the SR icon)

## logo/
Wordmark with the dashed ramp. SVG for web and print, 2400px transparent PNG for slides and docs.
- `logo-on-dark`: white + orange, for dark backgrounds (used on the site)
- `logo-on-light`: dark + orange, for white backgrounds
- `logo-mono-white` / `logo-mono-black`: single color, for stamps, engraving, one-color print

## icon/
SR monogram with the small ramp. SVG + 1024px PNG.
- `icon-tile`: rounded dark tile (favicon / app icon)
- `icon-square`: full-bleed square, for places that apply their own rounding
- `icon-round`: circular crop
- `icon-orange-tile`: orange variant

## social/
- `og-image`: 1200×630 link-preview image
- `linkedin-banner`: 1584×396
- `avatar-round-800` / `avatar-square-800`: profile pictures
- `email-signature-600w`: logo for light-background email signatures
